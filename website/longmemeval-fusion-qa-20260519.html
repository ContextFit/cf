Configuration

LongMemEval-S cleaned, 500 total rows. ContextFit used the May 19 optional OpenAI fusion retrieval artifact, source-aware answer generation, top-10 retrieved context, and a 20,000 character per-session cap.

Reproduction Command

.venv/bin/python benchmarks/longmemeval_contextfit_qa.py \
  --data benchmarks/data/longmemeval_s_cleaned.json \
  --retrieval-artifact benchmarks/longmemeval_fusion_claim_966_987_20260519.json \
  --hypotheses-out benchmarks/longmemeval_contextfit_qa_hypotheses_fusion_source_aware_20260519.jsonl \
  --judged-out benchmarks/longmemeval_contextfit_qa_judged_fusion_source_aware_20260519.jsonl \
  --summary-out benchmarks/longmemeval_contextfit_qa_summary_fusion_source_aware_20260519.json \
  --source-aware \
  --top-k-context 10 \
  --max-session-chars 20000 \
  --generation-model gpt-4o-2024-08-06 \
  --judge-model gpt-4o-2024-08-06
